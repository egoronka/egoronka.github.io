Privacy Policy

Last updated: October 26, 2026

1. Summary

Survival Stories Uploader is a personal desktop tool used only by its owner. It does not collect, sell or share personal data of other people.

2. What data the app uses

  • TikTok access token — received after the owner signs in with TikTok. It is stored only on the owner's own computer and is used only to upload videos to the owner's account.
  • Basic profile info (scope user.info.basic) — used only to confirm which account is connected.
  • Videos — files created by the owner and uploaded to the owner's TikTok account (scopes video.upload and video.publish).

3. What the app does not do

  • It does not read other users' data, comments, followers or messages.
  • It does not send data to any server other than TikTok's official API.
  • It does not use analytics, ads or tracking.

4. Data removal

The owner can revoke the app's access at any time in TikTok settings (Security → Manage app permissions). Deleting the local token file removes all stored data.

5. Changes

This policy may be updated. The date at the top of this page shows the latest version.
